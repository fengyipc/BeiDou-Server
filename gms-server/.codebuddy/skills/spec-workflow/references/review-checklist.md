# 代码审查清单 Review Checklist

## 基本审查项

### 功能性审查
- [ ] 代码实现了需求规格中描述的功能
- [ ] 所有分支路径都被正确处理
- [ ] 错误处理逻辑完善
- [ ] 边界条件已考虑

### 安全性审查
- [ ] 无 SQL 注入风险（使用参数化查询）
- [ ] 输入参数已校验
- [ ] GM 权限分级正确
- [ ] 敏感信息不暴露在日志中
- [ ] 封包校验正确

### 代码质量审查
- [ ] 命名符合规范（类/方法/变量）
- [ ] 代码格式符合规范（缩进、空格、大括号）
- [ ] 方法长度 ≤100 行
- [ ] 注释清晰（解释为什么，不重复代码）
- [ ] 无调试代码残留
- [ ] 无注释掉的代码
- [ ] 无魔法数字（使用常量）

### 性能审查
- [ ] 数据库查询已优化（有索引）
- [ ] 无 N+1 查询问题
- [ ] 使用批量操作而非循环单条
- [ ] 线程安全正确（ConcurrentHashMap 等）
- [ ] 资源正确释放（try-with-resources）

### 测试覆盖
- [ ] 核心逻辑有单元测试
- [ ] 测试用例覆盖主要场景
- [ ] 测试可重复执行

### 文档审查
- [ ] Javadoc 完整
- [ ] 相关文档已更新
- [ ] API 变更已同步

### 网络通信
- [ ] 封包格式正确
- [ ] 封包加密/校验正确
- [ ] 心跳处理正确
- [ ] 重连逻辑正确

- [ ] 技能效果正确实现

- [ ] 事务原子性保证

- [ ] 离线数据处理正确

## 审查标记说明

| 标记 | 含义 | 必须处理 |
|------|------|----------|
| `[must-fix]` | 严重问题，必须修复 | 是 |
| `[should-fix]` | 应该修复 | 建议 |
| `[suggest]` | 建议改进 | 可选 |
| `[nit]` | 小问题（格式） | 可选 |
| `[question]` | 需要澄清 | 必须回复 |

---

## 审查结论

| 结论 | 条件 |
|------|------|
| ✅ Approved | 所有 `[must-fix]` 已处理 |
| ⚠️ Requested Changes | 有未处理的 `[must-fix]` |
| ❌ Rejected | 有严重架构或安全问题 |
