# 功能规范文档 Specs

本目录存放所有功能规范文档。

## 目录结构

```
01-specs/
├── README.md           # 本文件
├── 001-功能名称/       # 按功能模块组织的规范
│   ├── spec.md        # 功能规范
│   ├── plan.md        # 技术计划
│   ├── tasks.md       # 任务清单
│   └── review.md      # 审查记录
└── index.md           # 规范索引
```

## 规范编号规则

`SPEC-YYYY-NNN`
- `YYYY`: 年份（4位）
- `NNN`: 序号（3位，不足补零）

示例：`SPEC-2026-001`

## 状态说明

| 状态 | 说明 |
|------|------|
| `draft` | 草稿中 |
| `clarifying` | 澄清中 |
| `approved` | 已批准 |
| `implemented` | 已实现 |
| `deprecated` | 已废弃 |

## 创建新规范

当需要开发新功能时：

1. 在 `01-specs/` 下创建新目录
2. 复制 `templates/spec-template.md` 作为基础
3. 填写规范内容
4. 提交后进入 Plan 阶段
