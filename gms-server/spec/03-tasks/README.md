# 任务清单 Tasks

本目录存放任务清单文档。

## 目录结构

```
03-tasks/
├── README.md           # 本文件
└── [关联Plan编号]/     # 按 Plan 关联组织
    └── tasks-xxx.md   # 任务清单
```

## 任务编号规则

`TASKS-YYYY-NNN`
- `YYYY`: 年份
- `NNN`: 序号

示例：`TASKS-2026-001`

## 任务状态

| 状态 | 说明 |
|------|------|
| `pending` | 待开始 |
| `doing` | 进行中 |
| `blocked` | 阻塞中 |
| `done` | 已完成 |
| `cancelled` | 已取消 |

## 任务优先级

| 优先级 | 说明 |
|--------|------|
| `P0` | 必须完成（阻塞主线） |
| `P1` | 应该完成（本功能核心） |
| `P2` | 可以完成（增强功能） |
| `P3` | 后续处理（优化改进） |

## 任务分类

| 前缀 | 分类 | 说明 |
|------|------|------|
| `DB-` | 数据库 | 数据库相关任务 |
| `SVC-` | 服务 | 后端服务开发 |
| `NET-` | 网络 | 网络协议相关 |
| `SCR-` | 脚本 | 脚本系统相关 |
| `TEST-` | 测试 | 测试相关 |
| `DOC-` | 文档 | 文档相关 |
