## 总览：等级段与区域对照

```
等级段       主要区域
──────────   ──────────────────────────────────────────────
Lv.1~10      彩虹岛
Lv.10~20     射手村、勇士部落、魔法密林、废弃都市
Lv.20~30     阿里安特、废弃都市下水道、天空之城（低层）、水下世界浅海
Lv.30~40     玩具城、蘑菇王国、黄金海岸、魔法密林（深处）
Lv.40~50     武陵桃园、百草堂、林中之城、玛加提亚（低层）、地球防御本部
Lv.50~60     冰峰雪域、林中之城深处（龙穴入口）、武陵桃园
Lv.60~70     玛加提亚、勇士部落（骷髅区）、童话村、百草堂
Lv.70~80     神木村（森林区）、冰峰雪域（深处）、林中之城深处（牛魔王区）
Lv.80~90     神木村（半人马区）、时间停止之湖（海贼/死灵区）、冰峰雪域
Lv.90~100    神木村（龙之峡谷）、水下世界深海、时间停止之湖（时之鬼）
Lv.100~120   神木村（龙之巢穴）、时间神殿（追忆之路）、新加坡（乌鲁城）
Lv.120~140   时间神殿（后悔/忘却之路）、帕普拉图斯、扎昆
Lv.140~160   暗黑龙王、时间神殿（深处）
Lv.160~180   品克缤
```
