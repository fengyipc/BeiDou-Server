## 一、天空之城（Orbis, 200000000）

天空之城是漂浮于云端的妖精之城，以智慧女神雅典娜的神力维系悬浮。妖精与人类混居于此，但妖精掌管商贸与魔法工坊，人类多以寄居者身份存在。这里是神秘岛大陆的交通枢纽——通天塔自此向下延伸连接冰峰雪域与水下世界，航线则连通金银岛与玩具城。

### 1.1 莉萨（Lisa, NPC 2012012）

- **所在地图**：天空之城
- **职能**：多功能剧情枢纽 NPC——制作妖精之角、配制特殊治疗剂、推荐冒险者
- **人物形象**：温柔热心的妖精少女，天空之城的"万事通"。说话时爱用"~"结尾的语气，对冒险者彬彬有礼。拥有敏锐的识人之眼，被斯卡德委托推荐强者时总能精准挑选合适的人选。她还是一位旅行家，曾亲自前往水下世界游历，回来后对水之路的美景赞不绝口。
- **核心故事线**：
  - **"寂寞的波达"系列**（3053→3062，10 个任务）：发现流浪狗波达无法沟通，制作"妖精之角"翻译工具，配制特殊治疗剂为波达治伤，最终帮波达找到失散的主人何克。
  - **"斯卡德的新毛皮"**（3051→3052）：受冰峰雪域猎人斯卡德之托，物色强壮的冒险者前往雪域帮忙收集毛皮材料。
  - **"奇怪的预感"**（3115）：观测到一只巨大的金属鱼形物体穿过海面，引出海盗凯琳巴特要塞的发现。
  - **"海之风景"系列**（3091）：作为珂丽尔与妙斯之间的信息传递者，促成水世界相簿的跨区域任务。
- **经典台词**：
  - > "喂！旅行者~~如果有空的话来听听我的故事好吗~~"
  - > "对于被天空之城村庄附近的怪物袭击所受的伤，只有用我的特殊治疗剂才有效。我就算闭上眼睛也能做得出来。"
  - > "绝不能吃啊！！一定要记住。"（嘱咐冒险者将治疗剂涂抹于波达伤口而非食用）
- **关联人物**：波达（治疗对象）、何克（波达主人）、斯卡德（冰峰雪域，委托推荐冒险者）、珂丽尔（同城妖精，水世界相簿线索）、妙斯（水下世界，相簿销售者）

### 1.2 妖精 珂丽尔（Kriel the Fairy, NPC 2012011）

- **所在地图**：天空之城杂货店
- **职能**：杂货店主 + 核心剧情 NPC
- **人物形象**：骄傲而坦率的妖精，口头上对人类"毫无兴趣"，实际上却暗中关怀着不善社交的人类预言家斯皮罗纳。她自视甚高，认为妖精视角下的天空之城美景无可匹敌，曾对水下世界的美嗤之以鼻——直到亲眼看到水世界相簿后真诚地承认了自己的无知。与魔法密林的妖精维英是世交好友，维英家世代相传的宝物"凯柏洛斯之泪"她觊觎多年。
- **核心故事线**：
  - **"前往新世界"**（3042→3043）：接受维英委托的凯柏洛斯之泪，请冒险者帮忙收集魔法材料。
  - **"运送粮食给斯皮罗纳"**（3100）：发现斯皮罗纳的弟子多日未来采购粮食，担心她的安危，委托冒险者送去食物。
  - **"海之风景"**（3091）：从未去过海底的珂丽尔渴望看到水下世界的景色，最终被相簿中的海底美景折服。
- **经典台词**：
  - > "最近很多人类冒险者聚集在在天空之城里...但身为妖精的我很难理解。因为随时都可以展开翅膀任意飞翔。"
  - > "她虽然是人类但与其它人类的感觉有些不一样...性格虽然有些孤僻，但对人类却很好。"（评价斯皮罗纳）
  - > "水世界..真是太美了。还以为只是个蓝色海洋，但没想到海里竟然有这么美丽的地方..是我想的太简单了。"
- **关联人物**：妖精维英（魔法密林，世交好友）、斯皮罗纳（云彩公园，暗中关怀的对象）、莉萨（同城好友，水下世界旅行者）、妙斯（水下世界，水世界相簿）

### 1.3 保姆 珥玛（Elma the Housekeeper, NPC 2012010）

- **所在地图**：天空之城公园
- **职能**：赫拉家的保姆 + 果汁/料理制作 + 道具保管
- **人物形象**：温暖慈祥的老保姆，厨艺精湛，是天空之城公园的常驻居民。对阿尔冯丝小绿等年轻人充满母性关怀，总是笑盈盈地迎接来访者。唯一的缺点是健忘——斯皮罗纳借给她的喷云吐雾器，她足足忘了归还五十年。
- **核心故事线**：
  - **"阿尔冯丝小绿的食人花果汁"**（3048→3050）：用食人花蜜、椰子果等材料制作营养美味的食人花果汁，满足阿尔冯丝的渴望。
  - **"奈洛的礼物"**（3046）：帮助冒险者制作星月手镯——用来说服爱猫人士艾利逊。
  - **"赫拉失踪"**（3005→3007）：作为赫拉家的保姆，提供赫拉离家出走前的线索——赫拉反复提到一位"老太太"。
  - **"天空之城危机"**（3089→3090）：归还借了 50 年的喷云吐雾器给斯皮罗纳，用于修补天空之城的支撑云彩。
- **经典台词**：
  - > "您好啊~~原来是上次那位啊~~得到食人花汁了啊！"
  - > "喷云吐雾器？是 50 年前斯皮罗纳借给我的那个吗？好像我还没还给他哦。请稍等。"
  - > "我好不容易做好的食人花果汁，现在却弄丢了？...你要给我 300000 金币才可以拿走。"
- **关联人物**：赫拉（雇主的女儿）、阿尔冯丝小绿（云彩公园，食人花果汁的狂热爱好者）、艾利逊（天空之城公园，奈洛的礼物线索）、斯皮罗纳（云彩公园，喷云吐雾器原主人）

### 1.4 艾利逊（Ericsson, NPC 2012018）

- **所在地图**：天空之城公园
- **职能**：食人花蜜制作者 + 宠物猫爱好者
- **人物形象**：外表有些可怕的大叔，但对自己的黑猫"奈洛"有着近乎疯狂的溺爱。整日抱着奈洛在天空之城公园散步，对打扰他与猫相处的人极为不耐烦。他是天空之城唯一掌握食人花蜜制作技艺的人，但因阿尔冯丝小绿频繁骚扰，已经拒绝再为她制作——除非有人先为奈洛送上一份礼物。
- **核心故事线**：
  - **"阿尔冯丝小绿的食人花果汁"**（3044→3047）：拒绝为阿尔冯丝制作食人花蜜，直到冒险者送来星月手镯讨好奈洛后才答应。
  - **"奈洛的项链"**（3063→3064）：为奈洛一岁生日亲手做的项链丢失，委托冒险者购买材料重新制作；后又因怪物欺负奈洛而请冒险者清剿周边独角狮。
  - **"爱之证"**（1119）：用红独角狮尾制作爱的见证物。
- **经典台词**：
  - > "是阿尔冯丝小绿让你来的吧？...常常找我帮她做食人花果汁，真够烦人的。"
  - > "我正在和我的猫咪奈洛玩呢。不要妨碍我和可爱的猫咪玩啊。"
  - > "不是送给我可爱猫咪奈洛的礼物，干什么还拿来这里！快走开！"
  - > "你竟然把我用心做出的食人花蜜弄丢了？"
- **关联人物**：奈洛（黑猫宠物，生命中最重要的存在）、阿尔冯丝小绿（食人花果汁的纠缠者）、保姆珥玛（星月手镯制作者/食人花果汁制作者）

### 1.5 波达与何克（Moppie & Huckle, NPC 2012019）

- **所在地图**：波达——天空之城街头；何克——通天塔<神秘之室>
- **职能**：波达——剧情核心角色/沙子图团信使；何克——通天塔研究员
- **人物形象**：
  - **波达**：一只忠诚的流浪狗。主人何克留下"很快就回来"的承诺后投入研究一去不返，波达便一直蹲守在天空之城街头苦等。毛发脏乱、伤痕累累——它曾独自出城寻找主人，却被怪物袭击受伤。起初无法与人类沟通，只能"汪汪"叫唤；拥有莉萨制作的妖精之角后才能表达心声。得知主人还记得自己时感动流涕，后来鱼吃腻了也敢坦率表达不满——是个有主见的忠犬。
  - **何克**：沉迷研究自移动石头（魔法石）的学者，在通天塔秘密房间里一待就是 30 年。工作狂到完全忘记了曾经养的小狗波达。被提醒后充满愧疚："我怎么把可爱的波达给忘掉了呢...在我刚离开的时候还能把它放在我的笼子里到处走呢..."
- **核心故事线**：
  - **"寂寞的波达"系列**（3053→3062，10 个任务）：完整线索——发现波达 → 找莉萨制作妖精之角翻译语言 → 治疗波达伤口 → 了解波达心声 → 在通天塔找到何克 → 何克愧疚地为波达送鱼 → 波达最终吃腻了鱼。
  - **"沙子图团的补给品"**（2122→2126）：波达脖子上挂着写有"交给玩具城某人"的小箱子，是神秘组织沙子图团的传信犬。
  - **"何克的魔法材料收集"**（3038）：何克在通天塔研究 30 年自动石头，定期需要石球石片作为研究标本。
- **经典台词**：
  - > "汪~~汪汪~~汪汪汪汪~...呜~~~"（波达，使用妖精之角前）
  - > "听见我说什么了吗？...汪~好像一直听不懂我说的话，真麻烦。"（波达，使用妖精之角后）
  - > "疼痛消失了！汪~~不疼了！汪~~莉萨的能力真不是盖的！"（波达，治愈后）
  - > "我的主人正在天空之城塔安全的地方进行研究呢！汪~主人的名字叫何克！汪汪！"
  - > "鱼腥味儿真让我厌恶。主人知道的话会失望吧...可是我已经腻了。汪~千万不要再给我带鱼来了..."
  - > "我怎么把可爱的波达给忘掉了呢...居然一直在等着我这样的主人..."（何克）
- **关联人物**：莉萨（制作妖精之角、治疗波达）、何克（30 年未归的主人）

### 1.6 阿尔冯丝小绿（Alfonse Green, NPC 2012020）

- **所在地图**：云彩公园Ⅰ
- **职能**：纯剧情 NPC
- **人物形象**：居住在云彩公园的少女，对食人花果汁有着近乎痴迷的执念。光是想到果汁就会流口水，等待果汁时什么事都做不了。因为频繁纠缠艾利逊帮她制作食人花蜜，已被对方列入"拒绝服务"名单。天真烂漫，喝到果汁后"感到非常幸福快乐"。
- **核心故事线**：
  - **"阿尔冯丝小绿的食人花果汁"**（3044→3050，5 个任务）：想喝果汁 → 艾利逊拒绝 → 珥玛提供说服方案（给猫做礼物）→ 珥玛配制果汁 → 阿尔冯丝幸福微笑。
- **经典台词**：
  - > "我特别喜欢喝食人花果汁，啊！一想起那果汁就会流口水啊..."
  - > "可是因为我经常要求艾利逊大叔为我制作食人花汁，他一看到我去就不帮我做了。"
  - > "哇！终于来了啊。您不知道我等得多么辛苦，光是想着好吃的食人花果汁，什么事都做不了。"
- **关联人物**：艾利逊（食人花蜜制作者，被她烦透）、保姆珥玛（果汁制作者，像母亲般关怀她）

### 1.7 秀兹（Hughes the Fuse, NPC 2012017）

- **所在地图**：通天塔<秀兹的研究室>（地下水域房间）
- **职能**：发明家 + 任务 NPC
- **人物形象**：性格乖僻的天才发明家，自封"天才秀兹"。独自居住在通天塔地下被水包围的研究室中，收藏着各种宝贝（尤其是小海豹玩偶）。对闯入研究室的人极为暴躁，但一旦认可对方就会慷慨地展示自己的发明。自恋至极——"能亲眼见到我的天才发明，你应该感到光荣才对"——但骨子里其实很孤独。
- **核心故事线**：
  - **"秀兹的兴趣"**（3065）：冒险者不慎弄坏了秀兹珍贵的小海豹玩偶，被迫消灭 50 只潜水企鹅王并带回玩偶赔偿。
  - **"秀兹的奇怪发明"**（3066）：发明了水中呼吸装置"氧气桶"——这是冒险者进入水下世界的关键道具。
  - **"秀兹的研究材料"**（3068）：周期性地需要海象尖牙和海狮皮革作为研究材料。
  - **"秀兹需要橡皮擦"**（9412）：研究计算需要大量铅笔和橡皮擦，全部用完后无法继续工作。
- **经典台词**：
  - > "不要碰我的宝箱！你是谁？怎么进来的。这里所有的东西都是我的，不许碰！"
  - > "你看这么出色的东西是我发明的，呼呼...只要有了这个，在水中也能呼吸。我确实是个天才，啊哈哈哈！"
  - > "能亲眼见到我的天才发明，你应该感到光荣才对~！"
  - > "不想帮我吗，难道对我一点都不觉得感激吗？我还为你做了一个氧气筒呢。"
- **关联人物**：妙斯（水下世界动物园，提及秀兹的发明）、波达/何克（同在通天塔区域）

### 1.8 斯皮罗纳（Spiruna, NPC 2032001）

- **所在地图**：老婆婆之屋（云彩公园深处，精灵出没区域内的小屋）
- **职能**：预言家 + 黑水晶精炼师（完成任务后开放）
- **人物形象**：隐居云彩公园的人类女预言家，拥有超越常人的感知力——"她虽然是人类但与其它人类的感觉有些不一样"。性格极度孤僻暴躁，不喜欢被打扰，动辄威胁降低来访者的人气。但在粗暴的外表下，她实际上一直在通过冥想守护天空之城，对这座浮空之城的安危忧心忡忡。连妖精珂丽尔都尊她为"人类中的稀有存在"。与弟子赫拉同住。
- **核心故事线**：
  - **"天空之城的危机"**（3086→3090，5 个任务）：预言天空之城将坠落大地。经冥想查明原因——精灵吸收云彩中的魔力并使用风属性魔法削弱支撑云层，导致城市下沉。指导弟子赫拉带领冒险者消灭精灵、收集魔云碎片、取回被珥玛借走 50 年的喷云吐雾器修补云彩。
  - **"斯皮罗纳的烦心事"**（3097→3098）：发现精灵日益凶恶化与女神之塔的出现有关，查明幕后黑手为"远古精灵"，引导冒险者组队进入女神之塔讨伐。
  - **"女神的宠物"**（3111→3114）：通过水晶球观察到古代生物艾利杰因女神被绑架而暴怒，指导冒险者平息其怒火。
  - **"寻找《上古魔书》"**（3009→3015）：与赫拉一同参与上古魔书大线——保管黑水晶、提供妖精之粉线索、最终揭示赫拉的真实身份。
- **经典台词**：
  - > "好没礼貌。竟然随便进入他人房间。"
  - > "啊啊...就为那件事过来的？不是什么大事。不久后天空之城将会坠落至大地。会比你想象的快。"
  - > "是充满自信，还是自满？你真以为你能救天空之城吗？没用的。"
  - > "你还真烦邪！如果你胆敢再来打扰我，小心我把你赶出去！"
  - > "走开，我在冥想。"
- **关联人物**：赫拉（弟子）、珂丽尔（送粮食的妖精顾客）、珥玛（50 年前借走喷云吐雾器）、艾利杰（通过水晶球观察的对象）、阿尔卡斯特（冰峰雪域，上古魔书主线）

### 1.9 赫拉（Hella, 斯皮罗纳的弟子）

- **所在地图**：老婆婆之屋（云彩公园）
- **职能**：斯皮罗纳的弟子与代言人

## 四、通天塔：连接三界的纽带

通天塔（Orbis Tower）是贯穿天空之城、冰峰雪域与水下世界的巨大垂直建筑，从天空之城的云端向下延伸至海底水路。塔内栖息着各类魔法生物——石球、企鹅、暗黑生物——并隐藏着多个秘密空间。

### 通天塔中的关键人物


| 人物        | 位置              | 角色                    |
| --------- | --------------- | --------------------- |
| **何克**    | 通天塔<神秘之室>       | 波达的主人，研究自移动石头 30 年的学者 |
| **秀兹**    | 通天塔<秀兹的研究室>（地下） | 天才发明家，发明水中呼吸氧气桶       |
| **查里中士**  | 天空之城（塔顶区域）      | 阿尔法部队驻军，执行调查任务        |
| **伊吉上等兵** | 云彩公园Ⅵ（塔上方区域）    | 阿尔法部队，持有记忆之粉          |
| **巴伯下士**  | 寒冰平原（塔下方区域）     | 阿尔法部队，调查古代文件          |
| **雕像**    | 通天塔<8 层>        | 《上古魔书》的藏匿处            |
| **魔法石**   | 通天塔 1 层 / 20 层  | 何克研究的移动装置，使用觉醒卷轴可传送   |


### 通天塔的叙事意义

通天塔不仅是物理上连接三大区域的交通要道，更是剧情上编织三界命运的纽带：

1. **《上古魔书》的终点**：阿尔卡斯特（冰峰雪域）发起的探索，经过天空之城多位 NPC 的线索接力，最终在通天塔 8 层的雕像中发现了魔书。
2. **水下世界的入口**：秀兹在塔底发明了氧气桶，使冒险者得以进入水下世界——没有这位"天才"的发明，水族之城将与地面世界隔绝。
3. **军事联络线**：阿尔法部队的成员分布在塔的不同层级区域——从天空之城到寒冰平原，通过通天塔串联成一张覆盖整个神秘岛的军事网络。
4. **何克的遗忘**：一位学者在塔中沉迷研究 30 年，忘记了忠犬波达——通天塔既是知识的殿堂，也是人情疏离的象征。
