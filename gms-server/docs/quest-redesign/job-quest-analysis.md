## 二、任务线模式分析

从现有职业任务中可以归纳出以下 **标准模式**：

### 模式 A：新手修炼链 (Lv1~40)
```
新手修炼场 → 丢失的表彰 → 恢复自尊心(获得技能书) → 使用技能(击杀) → 团体打猎(组队)
          → 新手修炼1~4阶(击杀递增) → 遇见古董收藏商 → 让我看看你的本事 → 报告结果
```
**特点**: 每个冒险家职业+对应骑士团职业共享一套。约 15~20 个任务。

### 模式 B：中段剧情链 (Lv30~70)
```
古董搜索/传说/远古XX → 多步交物品/击杀 → 最终章(击杀BOSS,获得专属装备+勋章)
```
**特点**: 冒险家+骑士团配对共享。约 4~8 个任务。

### 模式 C：终极之路 (Lv120, 3转→4转)
```
XX的介绍信(交信件) → 真实的故事1 → 真实的故事2 → 真实的故事3 → 英雄的潜力(交2份材料)
```
**特点**: 五大冒险家职业各一套（战/法/弓/飞/海），固定 5 步。需 3 转职业。

### 模式 D：4转专属技能线 (Lv120+)
```
NPC对话开启 → 收集材料1 → 剧情推进 → 收集材料2 → ... → 获得终极技能
```
**特点**: 每个 4 转细分职业独享。如：
- 火毒大法师：逆属性(火毒) 5步 → 获得技能 2121005
- 冰雷大法师：逆属性(雷冰) 5步 → 获得技能 2221005
- 主教：飞龙的心脏 5步 → 强化圣龙技能 2321003
- 黑骑士：灵魂治愈 4步 + 灵魂祝福 4步

### 模式 E：全职业系列线 (Lv45~105)
```
吉欧的第1次委托(Lv45) → 第2次(Lv50) → ... → 第13次(Lv105) [材料递增,经验递增]
威尔斯的新技术(Lv45) → 第二次教导(Lv75) → 第三次教导(Lv105) [技能习得]
```
**特点**: 不限职业，作为等级成长的通用任务填充。

## 四、扩展任务线方案

### 方案 1: 新增自定义职业任务线

按照现有模式，一条完整的新职业任务线应包含以下文件修改：

#### 需修改的文件

| 文件 | 作用 | 关键字段 |
|------|------|---------|
| `Quest.wz/QuestInfo.img.xml` | 定义任务名称、描述、分类 | `name`, `parent`(任务线名), `area`(=10), `order` |
| `Quest.wz/Check.img.xml` | 定义接受/完成条件 | `0`(接受): `lvmin`, `job`, `quest`(前置), `npc` / `1`(完成): `item`, `mob` |
| `Quest.wz/Act.img.xml` | 定义奖励/后续 | `1`(完成): `exp`, `item`, `skill`, `job`(转职), `nextQuest` |
| `Quest.wz/Say.img.xml` | NPC 对话脚本 | 对话文本 |

#### 任务 ID 分配规则

从现有数据可归纳:
- `2xxx`: 新手/1转引导类
- `6xxx`: 职业专属进阶任务 (6000~6999 范围)
- `28xxx`: 冒险家+骑士团共通任务线

**建议**: 自定义任务使用 `7000~7999` 或 `29000~29999` 范围

#### 标准任务线模板 (以 5 步任务链为例)

```xml
<!-- QuestInfo.img.xml -->
<imgdir name="7000">
    <string name="name" value="任务名称1" />
    <string name="parent" value="你的任务线名称" />
    <int name="area" value="10" />
    <int name="order" value="1" />
    <string name="0" value="接受描述" />
    <string name="1" value="进行中描述" />
    <string name="2" value="完成描述" />
</imgdir>

<!-- Check.img.xml -->
<imgdir name="7000">
    <imgdir name="0"> <!-- 接受条件 -->
        <int name="npc" value="NPC_ID"/>
        <int name="lvmin" value="120"/>
        <imgdir name="job">
            <int name="0" value="112"/> <!-- 英雄 -->
        </imgdir>
    </imgdir>
    <imgdir name="1"> <!-- 完成条件 -->
        <int name="npc" value="NPC_ID"/>
        <imgdir name="item">
            <imgdir name="0">
                <int name="id" value="ITEM_ID"/>
                <int name="count" value="10"/>
            </imgdir>
        </imgdir>
    </imgdir>
</imgdir>

<!-- Act.img.xml -->
<imgdir name="7000">
    <imgdir name="0"/> <!-- 接受时动作(通常空) -->
    <imgdir name="1"> <!-- 完成时奖励 -->
        <int name="exp" value="500000"/>
        <int name="nextQuest" value="7001"/>
    </imgdir>
</imgdir>
```

### 方案 2: 分阶段扩展建议

#### 阶段 1 - 补齐缺失的对称性
当前骑士团(魂/炎/风/夜/奇)没有独立的 4 转技能专属线，只有与冒险家共享的新手/中段线。可参照冒险家 4 转专属模式(模式 D)为骑士团补齐：

```
骑士团-魂骑士(4转) → 类似 "被遗忘的战歌" 模式
骑士团-炎术士(4转) → 类似 "逆属性" 模式
骑士团-风灵使者(4转) → 类似 "传说中的火鸟" 模式
骑士团-夜行者(4转) → 类似 "黑暗匕首" 模式
骑士团-奇袭者(4转) → 类似 "时空变形" 模式
```

#### 阶段 2 - 增加高等级内容
- Lv150+ 新任务线（目前 Lv120~200 之间任务空缺较大）
- Lv200 终极任务的前置链扩展

#### 阶段 3 - 跨职业互动
- 参考"全职业通用"模式，添加多职业协作任务线
- 如：战士+魔法师协作任务、弓手+飞侠协作任务
