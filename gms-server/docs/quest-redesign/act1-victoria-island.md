# 第一幕：金银岛（Lv10~35）

## 概述

第一幕为现有的职业任务线 → 地狱大公主线，**不做改动**。本文档的核心工作是：

1. 将金银岛剩余的非主线任务（约 250 个）整理为 **10 条副线 + 若干支线**
2. 设计地狱大公之后 → 天空之城的 **衔接任务**

## 二、第一幕 → 第二幕衔接（已实现）

地狱大公被击败后，通过 1 个新建任务 + 2 个现有任务（3042→3043）将玩家自然引导至天空之城。

### 任务链流程

```
28283（为了金银岛的和平） --nextQuest--> 30040（记忆者的发现） --nextQuest--> 3042（转交神秘的材料） --nextQuest--> 3043（珂丽尔的忙） --对话引导--> 斯皮罗纳（第二幕入口）
```

### 衔接任务详细设计

| 步骤 | Quest ID | 任务名 | Start NPC | End NPC | 改动类型 | 设计要点 |
|------|----------|--------|-----------|---------|---------|---------|
| 0 | 28283 | 为了金银岛的和平 | 记忆者 (1061011) | 记忆者 (1061011) | **改编** | Act.img 添加 `nextQuest=30040` |
| 1 | **30040** | 记忆者的发现 | 记忆者 (1061011) | 维英 (1032106) | **新建** | 28283 完成后自动触发。记忆者在地狱大公残留魔力中发现远古魔法痕迹，建议去魔法密林找维英打听天空之城消息。到维英处完成。 |
| 2 | 3042 | 转交神秘的材料 | 维英 (1032106) | 珂丽尔 (2012011) | **改编** | lvmin 40→30，添加前置条件（30040已完成）。对话改为承接30040叙事，维英委托玩家将凯柏洛斯之泪带给珂丽尔，提及天空之城不太平。 |

### 实现方式：纯 WZ 修改（无脚本）

现有任务 28283/3042/3043 均无 JS 脚本，完全靠 WZ 数据驱动。改编同样采用纯 WZ 方式。

**已修改的文件**（均在 `wz-zh-CN/Quest.wz/` 下）：

| 文件 | Quest ID | 操作 |
|------|----------|------|
| Act.img.xml | 28283 | 添加 `nextQuest=30040` |
| QuestInfo.img.xml | 30040 | 新增条目（parent=前往新世界, order=0） |
| Check.img.xml | 30040 | 新增：start(npc=1061011, lvmin=30, 前置28283) / complete(npc=1032106) |
| Act.img.xml | 30040 | 新增：exp 3000 + nextQuest=3042 |
| Say.img.xml | 30040 | 新增完整对话（记忆者揭示远古魔力 → 维英确认天空之城异常） |

| Say.img.xml | 3042 | 替换对话（承接30040叙事，委托送凯柏洛斯之泪） |
| Say.img.xml | 3043 | 替换对话（完成后引导至斯皮罗纳，提及城市下沉） |

### 玩家体验流程

1. 完成 28283（击杀地狱大公）→ 自动弹出 30040
2. 记忆者揭示远古魔力线索 → 接受 → 前往魔法密林
3. 找到维英确认天空之城异常 → 完成 30040（+3000 exp）→ 自动弹出 3042
4. 维英委托送凯柏洛斯之泪 → 接受 → 乘飞船前往天空之城
5. 交付珂丽尔 → 完成 3042（+2000 exp）→ 自动弹出 3043
6. 珂丽尔委托收集材料（空瓶×20 + 独角狮皮×200 + 独角狮角×50）
7. 交付材料 → 完成 3043（+25000 exp + 卷轴）→ 珂丽尔告知城市下沉 → 引导去找斯皮罗纳
8. 进入第二幕·神秘岛主线

#### 新建任务：不认识的女人·安息

紧接 2072"陌生女人的真相"之后。玩家已知她是幽灵、道符复活会变僵尸。

**任务 A：她的名字（Lv30）**

- **接取**：不认识的女人（废都医院）
- **对话要点**：她说"我连自己的名字都不记得了……如果能知道我是谁，也许就能安心了。"请冒险者去找魔法密林的汉斯，询问是否有帮助亡魂找回记忆的方法。
- **流程**：
  1. 前往魔法密林找汉斯。汉斯回忆说废都医院很久以前发生过一场事故，他翻阅古籍找到一种"记忆唤醒香"的配方——需要收集 20 个自由灵魂 + 10 个诅咒娃娃 + 1 个圣水。
  2. 收集材料交给汉斯，制成记忆唤醒香。
  3. 将记忆唤醒香带回废都医院。
- **完成奖励**：经验 8,000 + 记忆唤醒香 ×1
- **对话关键**：汉斯叹息："又是黑魔法的残留……那些被遗忘的灵魂，都是我年轻时的错。" （与「人与妖精」副线中汉斯的自责形成呼应）

**任务 B：最后的温暖（Lv30）**

- **接取**：自动触发（任务 A 完成后）
- **对话要点**：使用记忆唤醒香后，她想起了自己的名字和生前的事——"我想起来了……我叫……我有一个很爱我的人。他一定还在某个地方等着我。" 她请冒险者把她留下的一枚旧戒指交给废都酒吧的达克鲁，因为达克鲁"什么都知道"，也许能帮忙找到那个人。
- **流程**：
  1. 将旧戒指交给达克鲁。达克鲁沉默片刻，说："我知道这枚戒指的主人。" 他拿出一封陈旧的信——是那个人多年前托达克鲁保管的，一直在等她回来。
  2. 将信带回废都医院交给她。
- **完成对话**：她读完信后流下眼泪（或者说出某种只有幽灵才有的表达方式）。"原来他一直在等我……谢谢你。我现在可以安心了。" 她的身影逐渐变得透明，化为光点消散。"这里……终于不冷了。"
- **完成奖励**：经验 15,000 + 人气 5 + 特殊药水 ×10
- **后续效果**：NPC 外观不变，但对话切换为安详状态——"这里不再冷了……谢谢你。我可以安心地待在这里了。"（通过 `Say.img.xml` 中的任务完成状态条件控制对话分支）

**任务 C：未知的恋情（Lv85，改编现有 8051）**

- **定位**：安息结局的远期后续。NPC 仍为"不认识的女人"，对话内容根据任务状态变化。

- **涉及 NPC**：不认识的女人（原有）+ 达克鲁（原有）。不新增 NPC、不新增物品。
- **完成奖励**：保持原有奖励（经验 10,000 + 手套敏捷卷轴等）
