# 更新日志

本文档记录了 BeiDou-Server（MapleStory 游戏服务器模拟器）的所有版本变更信息。

---

## 1. 更新日志格式说明

本项目采用 **Semantic Versioning（语义化版本）** 规范，结合 **Keep a Changelog** 格式进行版本记录。

### 1.1 版本号规范

版本格式：`主版本.次版本.修订版本`

| 等级 | 说明 | 适用场景 |
|------|------|----------|
| 主版本 (Major) | 不兼容的API变更 | 重大架构调整 |
| 次版本 (Minor) | 向后兼容的新功能 | 功能新增 |
| 修订版本 (Patch) | 向后兼容的缺陷修复 | Bug修复、安全更新 |

### 1.2 记录格式

```markdown
## [版本号] - 发布日期

### 新增
- 功能描述

### 优化
- 优化描述

### 修复
- 修复描述

### 汉化
- 汉化描述
```

### 1.3 更新类型说明

| 类型 | 前缀 | 说明 |
|------|------|------|
| 新功能 | `feat:` | 新增的功能 |
| 修复 | `fix:` | 缺陷修复 |
| 优化 | `perf:` | 性能优化 |
| 重构 | `refactor:` | 代码重构 |
| 汉化 | `汉化:` | 文本中文化 |
| 文档 | `docs:` | 文档更新 |
| 测试 | `test:` | 测试相关 |
| 样式 | `style:` | 代码格式调整 |

## 3. 提交信息规范

### 3.1 Commit Message 格式

```
<type>: <subject>

<body>
```

### 3.2 Type 类型

| 类型 | 说明 |
|------|------|
| feat | 新功能 |
| fix | Bug修复 |
| docs | 文档 |
| style | 格式（不影响代码） |
| refactor | 重构 |
| perf | 性能优化 |
| test | 测试 |
| chore | 构建/工具 |

### 3.3 示例

```
feat: 新增任务达人戒指系统

- 新增任务达人戒指装备
- 新增戒指升级脚本
- 调整戒指属性

Closes #123
```

## 4. 版本发布流程

### 4.1 发布检查清单

- [ ] 所有功能测试通过
- [ ] 文档更新完成
- [ ] 版本号更新
- [ ] 更新日志记录
- [ ] Git Tag 标记

### 4.2 Git Tag 格式

```bash
# 创建版本标签
git tag -a v1.2.0 -m "版本说明"

# 推送标签
git push origin v1.2.0
```
