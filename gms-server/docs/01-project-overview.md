# 项目概述

## 1. 项目简介

BeiDou-Server 是一个基于 Java 开发的 MapleStory（冒险岛）私服项目，采用现代化的技术栈和模块化设计，提供稳定、高效的游戏服务端解决方案。

### 1.1 项目背景

该项目起源于 OdinMS Maple Story Server，经过多年的发展和优化，形成了一套完整的私服解决方案。项目名称"北斗"寓意指引方向，为开发者提供清晰的开发路径。

### 1.2 核心特性

- **高性能**: 基于 Netty 异步网络框架，支持高并发连接
- **模块化**: 清晰的模块划分，易于维护和扩展
- **多世界**: 支持多世界、多频道架构
- **跨平台**: 基于 Java 21，支持 Windows/Linux/MacOS
- **国际化**: 支持中英文多语言
- **脚本化**: 支持通过 JavaScript 脚本扩展游戏逻辑
- **数据驱动**: 使用 Flyway 进行数据库版本管理
- **现代框架**: 基于 Spring Boot 3.x 和 MyBatis-Flex

## 2. 技术选型

### 2.1 核心技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Java | 21 | 开发语言 |
| Spring Boot | 3.2.3 | 应用框架 |
| Netty | 4.1.109.Final | 网络通信 |
| MySQL | 8.4.0 | 数据库 |
| MyBatis-Flex | 1.8.9 | ORM 框架 |
| Druid | 1.2.22 | 数据库连接池 |

| FastJSON2 | 2.0.47 | JSON 处理 |
| SpringDoc | 2.5.0 | API 文档 |
| Flyway | 9.15.2 | 数据库迁移 |

### 2.2 网络框架

- **Netty**: 高性能异步事件驱动网络框架
  - 异步非阻塞 I/O
  - 零拷贝技术
  - 高效的线程模型

### 2.3 脚本引擎

- **GraalVM JS**: 高性能 JavaScript 引擎
  - 支持 ES6+ 语法
  - 优秀的性能表现
  - 与 Java 互操作性强

### 2.4 数据库层

- **MySQL 8.0+**: 关系型数据库
- **Druid**: 阿里巴巴数据库连接池
- **Flyway**: 数据库版本管理工具
- **MyBatis-Flex**: 灵活的 ORM 框架

## 3. 项目特点

### 3.1 架构设计

#### 分层架构
```
┌─────────────────────────────────┐
│         客户端 (Client)          │
└──────────────┬──────────────────┘
               │ 网络协议
┌──────────────▼──────────────────┐
│      网络层 (Netty Handler)     │
└──────────────┬──────────────────┘
               │ 封包处理
┌──────────────▼──────────────────┐
│     业务逻辑层 (Service)         │
├──────────────┬──────────────────┤
│  玩家系统 │ 地图系统 │ 任务系统 │
│  物品系统 │ 公会系统 │ 商城系统 │
└──────────────┬──────────────────┘
               │ 数据访问
┌──────────────▼──────────────────┐
│      数据访问层 (DAO/Mapper)     │
└──────────────┬──────────────────┘
               │ 数据存储
┌──────────────▼──────────────────┐
│         MySQL 数据库            │
└─────────────────────────────────┘
```

#### 模块划分
- **client**: 客户端连接和会话管理
- **server**: 游戏服务器核心逻辑
- **net**: 网络通信和封包处理
- **dao**: 数据访问对象
- **service**: 业务逻辑服务
- **controller**: Web API 控制器
- **scripting**: 脚本引擎和管理

### 3.2 关键特性

#### 1. 多世界支持
- 支持多个独立游戏世界
- 每个世界可配置不同的经验/金币/掉落倍率
- 动态添加/删除世界和频道

#### 2. 角色系统
- 完整的角色创建和管理
- 属性系统（力量、敏捷、智力、幸运）
- 技能系统和职业体系
- 装备和背包系统

#### 3. 地图系统
- 基于地图 ID 的地图管理
- 怪物刷新和 AI 系统
- 地图限制和传送机制
- 副本和任务地图支持

#### 4. 任务系统
- 支持主线、支线任务
- 任务前置条件检查
- 任务奖励发放
- 脚本化任务逻辑

#### 5. 脚本系统
- JavaScript 脚本引擎
- NPC 对话脚本
- 任务脚本
- 地图事件脚本
- 传送门脚本

#### 6. 公会系统
- 公会创建和管理
- 公会等级和经验
- 公会商店
- 公会联盟
